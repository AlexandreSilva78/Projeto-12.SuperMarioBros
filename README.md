# 🍄 Mario & Luigi - Encanadores Especializados

Veja o site em funcionamento clicando no link: https://alexandresilva78.github.io/Projeto-12.SuperMarioBros/

Site responsivo para empresa de serviços de encanamento com tema do Super Mario Bros, oferecendo uma experiência divertida e profissional para clientes que precisam de assistência hidráulica.

## ✨ Características Principais

- **Design Responsivo**: Adapta-se perfeitamente a dispositivos móveis e desktop
- **Tema Mario Bros**: Interface divertida com elementos icônicos dos personagens
- **Formulário de Contato Interativo**: Sistema suave de exibição/ocultação
- **Integração com WhatsApp**: Contato direto via mensagem
- **Vídeo de Fundo**: Atmosfera imersiva com tema do Mario
- **Animações CSS**: Transições suaves e efeitos hover

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível
- **CSS3**: Design moderno com Flexbox e animações
- **JavaScript**: Interatividade e controle de formulários
- **FormCarry**: Sistema de envio de formulários
- **Design Responsivo**: Media queries para adaptação mobile

## 🎯 Funcionalidades

### Navegação Intuitiva
- Menu header com links para Home, Serviços e Fale Conosco
- Efeitos hover coloridos nos links de navegação

### Seção Principal
- Apresentação visual com Mario e Luigi
- Descrição dos serviços de encanamento
- Call-to-action para solicitar orçamento

### Sistema de Contato
- Formulário deslizante com campos para:
  - Nome do cliente
  - Telefone para contato
  - Descrição do problema
- Integração com WhatsApp para contato rápido
- Máscara de fundo durante preenchimento do formulário

### Elementos Visuais
- Vídeo temático do Mario Bros em loop
- Gradientes e overlays para melhor legibilidade
- Logo do Mario em destaque
- Botões com efeitos de hover

## 📱 Responsividade

O site foi otimizado para:
- **Desktop**: Layout com dois painéis (texto e imagem)
- **Mobile**: Design em coluna única com elementos reorganizados
